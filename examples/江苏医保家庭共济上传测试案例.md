# 江苏医保家庭共济上传测试案例

> 本文件仅用于验证知识库上传、分块、向量化和检索流程，不是正式医保政策，不能作为实际业务办理依据。

## 案例背景

李女士参加南京市职工基本医疗保险，希望帮助母亲了解家庭共济办理流程。测试案例编号为 `JSYB-DEMO-2026-001`。母亲也是江苏省基本医疗保险参保人，但李女士目前还没有完成家庭成员关系绑定。

## 演示办理步骤

1. 李女士先进入测试系统中的“家庭共济”服务入口。
2. 阅读并确认演示使用说明，选择需要绑定的家庭成员关系“母亲”。
3. 完成演示身份校验后提交绑定申请。
4. 页面显示绑定成功后，再查看演示账户的共济使用状态。

## 演示所需信息

本案例只要求确认参保城市、参保险种、家庭成员关系和是否已经绑定。测试过程中不得输入真实身份证号、银行卡号、密码或短信验证码。

## 使用限制

上述步骤完全是项目功能测试数据，不代表江苏省或南京市医保部门的真实办理材料、入口、时限和待遇标准。实际办理必须查询江苏省医疗保障局、参保地医疗保障部门或江苏医保云发布的最新规定。

## 推荐测试问题

请向江苏医保 Agent 提问：“案例编号 JSYB-DEMO-2026-001 中，李女士想给母亲使用家庭共济，目前还缺少哪一步？”
